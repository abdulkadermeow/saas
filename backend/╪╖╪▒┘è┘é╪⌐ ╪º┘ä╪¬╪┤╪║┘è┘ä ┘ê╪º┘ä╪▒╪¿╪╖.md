# باك إند منصة رفيق ورفيقة — Laravel API فقط

## التشغيل

```bash
docker compose up -d --build
```

بعدها الـ API شغال على: `http://localhost:8080/api`

## التأكد أنه يعمل

```bash
# فحص سريع من المتصفح أو curl
curl http://localhost:8080/api/plans

# أو الفحص الشامل (10 نقاط: باقات، مصادقة، دفع، POS، n8n)
bash scripts/verify.sh http://localhost:8080/api
```

## ربطه مع أي فرونت إند

1. حدّث `FRONTEND_URL` في `backend/.env` لرابط الفرونت تبعك (مثلاً `http://localhost:5173` لمشروع Vite) — هذا يضبط الـ CORS.
2. من الفرونت: سجّل دخول وخزّن التوكن، ثم أرسله مع كل طلب:

```js
// تسجيل دخول
const res = await fetch('http://localhost:8080/api/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ email, password }),
});
const { token, user } = await res.json();

// أي طلب بعدها
await fetch('http://localhost:8080/api/subscription', {
  headers: { Authorization: `Bearer ${token}` },
});
```

## خريطة الـ API

| المسار | الوصف |
|---|---|
| `POST /api/auth/register` · `POST /api/auth/login` | إنشاء حساب / دخول — يرجع `token` |
| `GET /api/plans` | الباقات الثلاث (عام) |
| `GET /api/subscription` | اشتراك المستخدم + رصيد الرسائل |
| `POST /api/subscription/checkout` | إنشاء جلسة دفع — يرجع `checkout_url` |
| `GET/PUT /api/assistants/{rafiq\|rafiqa}` | إعدادات المساعدين |
| `GET /api/conversations` | المحادثات |
| `GET/POST /api/pos/connection` · `GET /api/pos/summary` | ربط POS (باقة الأعمال فقط) |
| `POST /api/pos/verify-license` | التحقق من ترخيص POS (عام) |
| `GET /api/n8n/assistant-config` · `POST /api/n8n/events` | جسر n8n (بهيدر `X-N8N-SECRET`) |
| `POST /api/webhooks/payments/{gateway}` | Webhook بوابة الدفع |
